## [1.0.0] — 2026-05-19

### Added
- Initial public release
- `figma-design` skill — design and build Figma screens from a project's design system
- `skill-creator` skill — create, evaluate, and self-improve Claude skills with eval tooling
- `plan-workflow` skill — create and maintain cross-chat persistent plans
- `defuddle-n8n` skill — fetch clean web content via n8n Defuddle workflow
- `raindrop-bookmarks` skill — search and manage Raindrop bookmarks via n8n
- `client-resources` skill — load client brand/design system context for downstream skills
- GitHub Actions workflow to auto-build `.plugin` on push and release
