# cowork-skills (legacy package)

**Transitional only.** This package bundles the original six skills for backward compatibility.

For new installs, use the marketplace plugins instead:

- `cowork-work` — design and Figma
- `cowork-utils` — research, planning, bookmarks, deployment, and skill authoring
- `cowork-life` — endurance coaching and personal wellness (as skills are refined)

See [PACKAGE-MATRIX.md](../../PACKAGE-MATRIX.md) for which skills ship in each package.
