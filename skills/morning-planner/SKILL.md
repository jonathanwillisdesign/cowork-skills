# Morning Planner

Design a structured, energising morning that sets up a productive day. The best mornings are intentional — not reactive.

## Before you start

Ask:
1. What time are you waking up / want to be at your desk?
2. What are today's 1–3 most important things to accomplish?
3. Any fixed commitments this morning? (calls, school run, meetings)
4. Is there a training session today? (factor into energy planning and timing)
5. Any energy or focus concerns? (tired, anxious, scattered, unmotivated)

## Designing the morning

### Non-negotiables first
Block out: training, family commitments, fixed meetings. These anchor the schedule.

### Protect the first 90 minutes
The first work block of the day is cognitively the most valuable. Protect it for deep, focused work — not email, not Slack, not admin.

### Review before diving in
A 5–10 minute orientation before starting work (using `daily-briefing`) prevents reactive work where you respond to what's loudest rather than what's most important.

## Output format

```
## Morning Plan — [Day, Date]

### Today's intention
[One sentence: what makes today a success?]

### Morning schedule

| Time | Activity | Duration | Notes |
|------|----------|----------|-------|
| 06:00 | Wake + hydrate | 5 min | Before reaching for the phone |
| 06:05 | [Training session] | 50 min | [Type — e.g. easy run 8km] |
| 06:55 | Shower + ready | 20 min | |
| 07:15 | Breakfast | 15 min | Away from screens |
| 07:30 | Daily briefing | 10 min | Orient on today's priorities |
| 07:40 | Deep work block 1 | 90 min | [Most important task] |
| 09:10 | Break | 10 min | Move, stretch, step outside |
| 09:20 | [Next session or meeting] | | |

### Today's top 3
1. [Most important task] — [why it matters today]
2. [Second priority]
3. [Third priority / backup if time allows]

### Energy forecast
[Note any meetings, context-switching, or energy demands to plan around]

### Watch out for
[Anything likely to distract or derail — proactively name it]
```

## Principles

- **No phone before 30 minutes of intentional activity** — reacting to notifications first thing sets a reactive tone
- **Deep work before meetings** — reverse if genuinely unavoidable, but protect it
- **Build in transitions** — back-to-back sessions with zero breathing room create cognitive fragility
- **One priority, not a list** — if you only get one thing done today, what is it?
