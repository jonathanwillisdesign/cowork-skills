# Running Coach

Create evidence-based, personalised running training plans — whether building a base, training for a race, or getting back after a break.

## Before you start

Ask:
1. **Goal**: race distance and target time / general fitness / return from injury?
2. **Current baseline**: weekly mileage, longest recent run, recent race times?
3. **Training days available per week**?
4. **Race date** (if applicable)?
5. **Experience level**: beginner / intermediate / advanced?
6. **Any injuries, niggles, or areas to protect**?
7. **Other training**: are you also cycling or swimming? (for load management)

## Training principles

- **80/20 rule**: ~80% of runs at easy/conversational pace, ~20% at quality (tempo/intervals)
- **Progressive overload**: increase weekly volume by no more than 10% per week
- **Recovery weeks**: every 3–4 weeks, drop total volume by 20–30% to absorb training
- **Long run**: typically 30–40% of weekly volume on the longest day

## Run types

| Type | Effort | Physiological purpose |
|------|--------|----------------------|
| **Easy / recovery** | Can hold a conversation | Aerobic base, active recovery |
| **Long run** | Easy to moderate | Endurance, fat adaptation |
| **Tempo** | Comfortably hard — could say a few words | Lactate threshold |
| **Intervals** | Hard — 1–5 min efforts with rest | VO2max, speed |
| **Strides** | 20 sec accelerations | Neuromuscular, form |

## Weekly plan format

```
## Running Plan: [Goal — e.g. "Sub-2hr Half Marathon"]
Week: [X of Y] | Phase: [Base/Build/Peak/Taper] | Total: ~[X]km

| Day | Session | Distance | Effort | Notes |
|-----|---------|----------|--------|-------|
| Mon | Rest | — | — | |
| Tue | Easy | 8km | Easy | Warm up, keep HR low |
| Wed | Tempo | 8km | Tempo | 2km easy, 4km tempo, 2km easy |
| Thu | Easy | 6km | Easy | Recovery pace |
| Fri | Rest / cross-train | — | — | |
| Sat | Long run | 18km | Easy–moderate | Fuel from 60min; walk if needed |
| Sun | Easy | 5km | Very easy | Shakeout, optional |
```

## Periodisation phases

| Phase | Duration | Focus |
|-------|----------|-------|
| Base | 4–8 weeks | Volume, aerobic development, consistency |
| Build | 4–8 weeks | Introduce quality sessions, progressive long runs |
| Peak | 2–3 weeks | Race-pace work, sharpen |
| Taper | 1–2 weeks | Reduce volume, maintain intensity |

## Weekly coaching check-in

Ask at the start of each new plan week:
- "How did last week feel? Any sessions that were significantly harder or easier than expected?"
- "Any soreness, tightness, or niggles to flag?"

Adjust the plan based on responses — don't mechanically follow a programme if the body is telling you otherwise.

## Integration with other skills

- Align hard run sessions with `meal-planning` (higher carbs night before long/hard sessions)
- If doing triathlon, coordinate with `triathlon-coach` for total weekly load
- Log the plan week in Tana or `morning-planner` for daily visibility
