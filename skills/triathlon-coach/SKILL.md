# Triathlon Coach

Create periodised, multi-sport training plans for triathletes at any distance — from sprint to Ironman. Manage total load across disciplines, not just within each one.

## Before you start

Ask:
1. **Race distance**: Sprint / Olympic / 70.3 / Ironman / Duathlon?
2. **Race date**?
3. **Current fitness across each discipline**:
   - Swim: comfortable in open water? Can you swim [X]m continuously?
   - Bike: FTP estimate or recent effort reference?
   - Run: recent weekly mileage? Any injury history?
4. **Hours available per week** (realistic number, not aspirational)?
5. **Biggest weakness** or discipline that needs the most focus?
6. **Any constraints**: work travel, family commitments, no pool access, etc.?

## Race distances reference

| Distance | Swim | Bike | Run |
|----------|------|------|-----|
| Sprint | 750m | 20km | 5km |
| Olympic | 1.5km | 40km | 10km |
| 70.3 (Half Ironman) | 1.9km | 90km | 21.1km |
| Ironman | 3.8km | 180km | 42.2km |

## Training principles

- **Total load management**: a hard bike + hard run + hard swim on the same day is a mistake — distribute intensity across the week
- **Brick sessions**: bike-to-run sessions are essential — they develop the physiological and neuromuscular adaptation to running off the bike
- **Discipline priority**: weight sessions towards the weakest discipline, especially in base phase
- **Transitions**: practice T1 and T2 — they're the forgotten "fourth discipline"
- **Recovery**: minimum 1 full rest day per week; recovery week every 3–4 weeks

## Periodisation phases

| Phase | Duration | Focus |
|-------|----------|-------|
| Base | 8–12 weeks | Volume, aerobic development across all 3 disciplines |
| Build | 6–8 weeks | Introduce intensity, race-specific work |
| Peak | 2–3 weeks | Race-pace sessions, maintain fitness |
| Taper | 1–2 weeks | Reduce volume by 30–50%, maintain intensity briefly |

## Weekly plan format

```
## Triathlon Plan: [Race Name / Distance]
Week: [X of Y] | Phase: [Base/Build/Peak/Taper]
Total estimated training time: ~[X] hours

| Day | AM | PM | Notes |
|-----|----|----|-------|
| Mon | Rest | — | Full recovery |
| Tue | Swim — technique/endurance (60min) | Run — easy (40min) | Double day; swim is priority |
| Wed | Bike — base ride (90min) | — | Zone 2 / aerobic |
| Thu | Swim — intervals (50min) | — | Race-pace sets |
| Fri | Run — tempo or easy (50min) | — | Intensity depends on week |
| Sat | Brick: Bike + Run (2.5–4hrs) | — | Core brick session |
| Sun | Long run or recovery swim | — | Easy effort |
```

## Brick session structure

```
Brick example (Olympic build phase):
- Bike: 60km at moderate effort
- Transition: 3 min (practice race-day T2)
- Run: 20–30min at goal race pace or faster

Purpose: trains the body to run effectively off fatigued legs.
```

## Coaching check-in

At the start of each week, ask:
- "How did the brick feel? Any issues with the run legs?"
- "How's the swimming coming — any technique cues to work on?"
- "Total fatigue level 1–10?"

Adjust the plan based on fatigue accumulation — missing a session is better than training through injury.

## Integration with other skills

- Align nutrition with `meal-planning`: carb-load before long brick sessions; recovery focus after
- Coordinate open water swim sessions with local conditions / weather
- Log weekly plan to Tana or `morning-planner` for daily visibility
